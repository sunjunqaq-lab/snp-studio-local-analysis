# SNP Studio 本地分析平台

## 1. 项目需求

这个项目围绕 SNP / 基因型数据做一个轻量分析工作台：

1. 在网页中导入样本按行、SNP 按列的基因型矩阵；
2. 完成格式校验、字段映射、样本缺失率、位点缺失率、MAF（最小等位基因频率）和质控过滤；
3. 展示质控后的样本、位点和可导出的记录；
4. 后端推理包提供固定 SNP 面板上的牛品种候选预测接口；
5. 用训练记录和准确率审计材料说明模型指标、适用范围和局限。

项目允许 AI 辅助生成代码，但核心数据流、接口约束和质控阈值需要能够自己讲清楚。


## 4. 端到端链路

### 4.1 前端浏览器质控链路

前端没有使用 Vue/React 框架，主要是原生 HTML/CSS/JavaScript。

1. **读取文件**：`input.js` 先检查文件后缀、大小和 UTF-8 编码，再读取文本内容。
2. **解析表格**：`matrix-core.js` 的 `parse()` 自动识别逗号、制表符、分号或空白分隔符，检查表头重复、行列数不一致等问题。
3. **字段映射**：用户确认样本 ID 列、表型列、基因型编码、缺失标记和忽略列。
4. **构建矩阵**：`build()` 把合法基因型存成数值矩阵；缺失值记为 `NaN`；硬调用只接受 0/1/2，剂量模式接受 0–2。
5. **计算描述性质控**：
   - 样本缺失率 = 该样本缺失位点数 / 总位点数；
   - 位点缺失率 = 该位点缺失样本数 / 保留样本数；
   - 计数等位基因频率 AF = 等位基因剂量总和 /（2 × 非缺失样本数）；
   - MAF = min(AF, 1 - AF)。
6. **过滤样本和位点**：`qc()` 先按样本缺失率过滤样本，再在保留样本中重新计算位点缺失率、AF 和 MAF，最后按位点缺失率、MAF、恒定位点等规则过滤。
7. **展示和导出**：页面展示矩阵预览、质控表、样本/位点统计，并可导出规范矩阵、质控后矩阵、样本质控 CSV、位点质控 CSV 和质控记录 JSON。

### 4.2 后端固定面板推理链路

后端使用 Python 标准库 `http.server` 提供 HTTP 接口，核心引擎在 `cattle.py`。

1. **加载模型**：`Engine.__init__()` 读取配置，校验 scikit-learn 版本、模型 schema、位点数、参考基因组和位点清单 SHA256。
2. **建立位点索引**：以 `(染色体, 位置, REF, ALT)` 为键，映射到模型特征轴位置。
3. **接收上传文件**：`server.py` 的 `POST /api/cattle/predict` 检查 Origin、文件大小、后缀和并发锁，文件先写入临时目录。
4. **解析基因型**：
   - VCF：读取 `#CHROM` 样本列，只接受 `PASS` 或 `.`，要求双等位 SNP、REF/ALT 属于 ACGT，并解析 GT 基因型；
   - CSV/TSV：第一列必须是 `sample_id` 或 `IID`，SNP 列名格式为 `chr:pos:REF:ALT`。
5. **匹配固定面板**：上传基因型按 77,068 个目标位点提取特征；面板覆盖度 = 已匹配位点数 / 面板位点数。
6. **样本质控**：样本缺失率 ≤ 15% 且面板覆盖度 ≥ 85% 才进入预测；否则标记为 `QC_REJECTED`。
7. **候选品种预测**：通过样本调用模型 `decision_function()`，按分数从高到低取前 3 个候选品种。
8. **返回结果**：输出样本 ID、状态、候选品种、分数、匹配位点数、覆盖度和提取后的 CSV 文本。

### 4.3 模型训练与评估链路

训练脚本在 `cattle-candidates-20261108.zip` 的 `train_cattle_candidate.py` 中。

1. 读取 manifest、样本元数据和基因型矩阵；
2. 检查样本 ID、品种标签、家系分组是否完整、重复；
3. 使用 `StratifiedGroupKFold` 按品种分层、按家系分组划分，避免同一家系同时出现在训练集和测试集；
4. 每个训练折内完成均值填补、标准化、可选 SVD 降维和模型拟合；
5. 收集折外预测，计算准确率、平衡准确率和宏平均 F1；
6. 最终模型用全部目标样本重新拟合，并通过 joblib 保存模型、类别、元数据和位点哈希。

当前 `.pyz` 内模型记录：988 头牛、52 个品种、77,068 个 SNP；线性 SVM 的分组交叉验证准确率为 81.28%，宏平均 F1 为 0.6330。该结果是固定预选面板上的开发集交叉验证结果，独立外测准确率为空，不能自动接受为鉴定结论。

## 5. 真实功能与模拟演示边界

### 5.1 前端真实执行的部分

- 文件格式和编码检查；
- 表格解析、字段映射和基因型合法性检查；
- 样本缺失率、位点缺失率、AF、MAF 计算；
- 样本/位点质控过滤；
- 矩阵、质控表和质控记录导出。

### 5.2 前端模拟演示的部分

- 模型训练；
- 关联分析 p 值、BH 校正 q 值；
- 24 个候选位点表；
- 科研图中的模型预测、折内/折外曲线和指标。

这些内容在页面和导出文件中标注为 `SIMULATED`，没有真正拟合模型，也没有使用上传数据做统计检验。

### 5.3 后端结果口径

- SVM 分数不是概率，也不是血统比例；
- 当前模型没有独立外部盲测集；
- 服务不自动转换参考基因组，输入必须确认是 ARS-UCD1.3；
- REF/ALT 冲突时不会自动翻转等位基因方向；
- 预测结果仅作为研究候选，需要人工复核。

## 6. 技术栈

- 前端：HTML、CSS、原生 JavaScript；可选 Web Worker 处理矩阵任务。
- 后端：Python、`http.server`、NumPy、scikit-learn、joblib。
- 部署：Python 标准库静态服务、Nginx 反向代理参考配置。
- 数据格式：CSV、TSV、TXT、PLINK RAW；后端另支持 VCF/VCF.GZ。
- 版本管理：Git 已初始化并推送到 GitHub 私有仓库；大体积压缩包、模型和运行时文件按 `.gitignore` 忽略。

## 7. 考核展示建议顺序

1. **讲需求**：说明这是一个 SNP 基因型导入、质控和品种候选预测演示平台。
2. **启动页面**：打开前端，加载内置 20 样本示例矩阵。
3. **演示数据输入**：展示文件解析、样本 ID/表型/SNP 列映射和编码选择。
4. **演示质控结果**：查看样本数、位点数、缺失率、MAF、通过/未通过位点和原因。
5. **演示导出**：导出质控后矩阵或质控记录 JSON，说明缺失值保留为 NA，没有填补。
6. **说明模型配置和科研图**：明确前端模型训练、关联检验和科研图是模拟演示。
7. **讲后端接口**：对照 `server.py` 和 `cattle.py` 说明上传、位点匹配、质控、Top3 候选预测链路。
8. **讲指标和局限**：说明交叉验证结果、没有独立外测、分数不是概率、需要人工复核。
